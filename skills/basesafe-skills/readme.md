## Useful Skill Groupings

### Agentic Red/Blue Teams

**battleprint** alternates red-team and blue-team agents to harden agentic code
**ai-fingerprint** is used by battleprint to inspect and characterize source code

### Promptfoo
**agentic-vulnerabilities-scan** guides the user through [promptfoo](https://www.promptfoo.dev/) setup and execution informed by source code inspection
**fingerprint** is used by agentic-vulnerabilities-scan to inspect and characterize source code

### Uncertainty Quantification 
**uncertainty-quantification** analyzes how uncertainty is represented, measured, calibrated, and operationalized across ML, AI, and agentic systems
**uq-metrics-evaluator** evaluates CSV-based model outputs for accuracy, calibration, and uncertainty using regression or classification metrics
